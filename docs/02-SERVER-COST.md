# 02. 서버 비용 예상

> 기준일: 2026-10-27. 환율 1달러 = 1,323원(2026-10-26 서울 외환시장 마감).
> 부품 가격은 변동이 크다. 특히 그래픽카드와 DDR5 램은 2026년 8~9월에 크게 올랐다. 구매 직전에 다시 확인할 것.

**권장:** PoC는 현재 노트북과 Kaggle로 비용 없이 진행한다. 시범 운영은 클라우드 GPU를 업무시간에만 켜서 월 20~30만 원대로 시작한다. 지금은 그래픽카드 가격이 비정상적으로 올라 있어서, 사용량이 1년 이상 꾸준히 확인된 뒤 사내 PC 구매를 검토한다. 단, 광고 소재가 외부 클라우드로 나가면 안 된다는 보안 요구가 있으면 처음부터 사내 PC로 간다.

## 사용량 가정

| 항목 | 값 |
|---|---|
| 업무시간 사용 | 하루 9시간 × 월 22일 = **월 198시간** |
| 24시간 상시 가동 | **월 730시간** |
| 이미지 1장 생성 시간 | 수십 초 수준 (참고: RTX 4090에서 FLUX 3 Klein 1280×1280 1장 약 28.5초, [adtestbench 측정](https://adtestbench.com/data/cloud-gpu-prices/)) |
| GPU 1장 처리량 | 시간당 100장 이상. 팀 단위 시범 운영에는 GPU 1장으로 충분 |

Z-Image-Turbo는 8스텝이라 위 참고치보다 빠를 가능성이 높다. 실제 수치는 PoC에서 측정해서 이 문서를 갱신한다.

## 1. 클라우드 GPU

시간당 요금 (2026-10-24 기준, [adtestbench](https://adtestbench.com/data/cloud-gpu-prices/), [RunPod](https://www.runpod.io/pricing), [AWS g6.xlarge](https://aws-pricing.com/g6.xlarge.html)):

| 서비스 | GPU | 시간당 | 업무시간 (월 198시간) | 상시 가동 (월 730시간) |
|---|---|---|---|---|
| RunPod Secure Cloud | RTX 4090 24GB | $0.89 | $176 ≈ **23.3만 원** | $650 ≈ 86.0만 원 |
| RunPod Secure Cloud | RTX 5090 32GB | $1.19 | $236 ≈ **31.2만 원** | $869 ≈ 114.9만 원 |
| RunPod Community Cloud | RTX 5090 32GB | $0.69 | $137 ≈ 18.1만 원 | $504 ≈ 66.6만 원 |
| AWS 서울 (ap-northeast-2) | L4 24GB (g6.xlarge) | $0.9896 | $196 ≈ **25.9만 원** | $722 ≈ 95.6만 원 |

- **Community Cloud**는 개인 호스트 장비라 안정성이 "가변적"이라고 RunPod 문서에 나와 있다. 사내 서비스에는 Secure Cloud를 쓴다.
- **AWS는 국내 리전**이라 데이터가 국외로 나가지 않는다. 1년 약정(Reserved, 선결제 없음)으로 상시 가동하면 월 $470 ≈ 62만 원까지 내려간다.
- 모델 파일 보관용 스토리지, 데이터 전송료는 별도다. 모델과 텍스트 인코더를 합쳐 수십 GB 수준이다.
- 업무시간에만 켜려면 출근 시 켜고 퇴근 시 끄는 스케줄러가 필요하다. 켤 때마다 모델 로딩에 몇 분 걸린다.

## 2. 사내 PC (온프레미스)

부품 가격은 2026년 10월 다나와 최저가 기준이다 ([그래픽카드](https://m.blog.naver.com/skdaksdptn/224431025338), [DDR5 64GB](https://prod.danawa.com/info/?pcode=30002663)).

### RTX 5070 Ti (16GB) 구성

| 부품 | 가격 |
|---|---|
| RTX 5070 Ti 16GB | 약 177만 원 |
| DDR5 64GB (32GB × 2) | 약 151만 원 |
| CPU, 메인보드, SSD 2TB, 850W 파워, 케이스 | 약 150~200만 원 (가정) |
| **합계** | **약 480~530만 원** |

### RTX 5090 (32GB) 구성

| 부품 | 가격 |
|---|---|
| RTX 5090 32GB | 약 884만 원 |
| DDR5 64GB (32GB × 2) | 약 151만 원 |
| CPU, 메인보드, SSD 2TB, 1200W 파워, 케이스 | 약 200~250만 원 (가정) |
| **합계** | **약 1,240~1,290만 원** |

- 그래픽카드 이외 부품 가격은 견적을 받지 않은 가정치다.
- RTX 5090은 1년 전 약 530만 원에서 지금 884만 원으로 올랐고, RTX 5070 Ti는 9월 첫째 주에만 117만 원에서 183만 원으로 올랐다. DDR5 램도 1년 전보다 약 5배다. 가격이 내려갈 신호는 아직 없다는 분석이 많다.
- RTX 5070 Ti(16GB)에서 MOSS 계열은 텍스트 인코더를 양자화해야 한다. 여유 있게 쓰려면 24GB 이상이 낫다.

### 전기료

한전 일반용(갑)Ⅰ 저압 전력량요금은 kWh당 여름 132.4원, 봄·가을 91.9원, 겨울 119.0원이다. 여기에 기후환경요금 9원, 연료비조정요금 5원이 붙는다. 연평균 약 **125원/kWh**로 계산한다 (부가세·전력기금 별도). ([한전 요금표](https://cyber.kepco.co.kr/ckepco/front/jsp/CY/D/C/CYDCHP00401.jsp), 2026년 4분기 동결)

| 구성 | 생성 중 소비전력 (가정) | 업무시간 내내 생성 (월 198시간) |
|---|---|---|
| RTX 5070 Ti PC | 약 450W | 89kWh ≈ **1.1만 원** |

실제로는 생성하지 않는 대기 시간이 길어서 이보다 적게 나온다. 초기 구매비에 비하면 무시할 수준이다.

## 3. 손익분기

사내 PC 구매비를 클라우드 월 비용으로 나눈 값이다. 전기료와 클라우드 스토리지 비용은 뺐다.

| 사내 PC | 비교 대상 클라우드 | 업무시간만 사용 | 상시 가동 |
|---|---|---|---|
| RTX 5070 Ti (약 500만 원) | RunPod RTX 4090 | 약 21개월 | 약 6개월 |
| RTX 5090 (약 1,265만 원) | RunPod RTX 5090 | 약 41개월 | 약 11개월 |

- **업무시간에만 쓰면 클라우드가 유리하다.** 사내 PC는 2~3년 이상 써야 본전이다.
- **24시간 상시 가동(야간 배치 생성, LoRA 학습 등)을 하면 사내 PC가 유리하다.** 6~11개월이면 본전이다.
- 사내 PC는 고장 시 대체 장비가 없고, 관리하는 사람의 시간이 든다. 클라우드는 장비 관리가 필요 없다.

## 4. 소프트웨어 비용

| 항목 | 비용 |

## 갱신 방법

PoC에서 실제 생성 시간을 측정하면 "사용량 가정"의 이미지 1장 생성 시간을 바꾸고, 필요한 GPU 수를 다시 계산한다. 부품을 살 때는 다나와 최저가와 견적을 다시 받아 "사내 PC" 표를 갱신한다.
